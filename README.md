# 文字起こし・話者分離: 公開案内

このリポジトリは、アプリの[プライバシーポリシー](https://kondofumikazu-cmd.github.io/conversation-transcriber-privacy/)と[サポート](https://kondofumikazu-cmd.github.io/conversation-transcriber-privacy/support.html)を GitHub Pages で公開するためのものです。アプリのソースコード、音声、文字起こし、モデルは含めません。

プライバシーに関する問い合わせは [GitHub Issues](https://github.com/kondofumikazu-cmd/conversation-transcriber-privacy/issues/new) から受け付けます。公開の Issue に音声や会話内容を添付しないでください。
