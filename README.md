# 文字起こし・話者分離: 公開案内

このリポジトリは、アプリの[プライバシーポリシー](https://kondofumikazu-cmd.github.io/conversation-transcriber-privacy/)、[サポート](https://kondofumikazu-cmd.github.io/conversation-transcriber-privacy/support.html)、[画面の例](https://kondofumikazu-cmd.github.io/conversation-transcriber-privacy/preview.html)を GitHub Pages で公開するためのものです。アプリのソースコード、音声、モデルは含めません。画面の例の会話は合成音声の実モデル解析結果を編集したものです。

プライバシーに関する問い合わせは [GitHub Issues](https://github.com/kondofumikazu-cmd/conversation-transcriber-privacy/issues/new) から受け付けます。公開の Issue に音声や会話内容を添付しないでください。
